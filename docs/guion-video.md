# Guion del video (3 a 8 minutos)

Es una guía de orden, no un texto para leer: cada uno explica con sus palabras lo que muestra en pantalla.
La voz de ambos debe escucharse clara y sin ruido de fondo.

| Minuto | Qué mostrar | Indicador |
|---|---|---|
| 0:00 | Qué es BodegaNube, los 4 microservicios y por qué cada uno tiene su propia base de datos | IE11 |
| 0:30 | Clonar el repositorio, `docker compose up -d` y seguir el README | IE10 |
| 1:15 | `mvn clean package` con pruebas y los `.jar` en `target/` | IE7 |
| 2:00 | Capas de un servicio; una entidad con `@OneToMany` y `@ManyToOne`; repositorio y controlador | IE2, IE5, IE6 |
| 2:45 | `application.properties` y `pom.xml` | IE4, IE8 |
| 3:30 | Servicios arriba; en Postman, login de operario y de comercio | IE3 |
| 4:15 | CRUD de productos y la fila en la base de datos (DBeaver o psql) | IE4, IE5 |
| 5:15 | Webhook, duplicado, picking y despacho con tracking | IE3 |
| 6:30 | Errores: 400, 401, 403, 404 y 409 con su mensaje | IE3 |
| 7:15 | Ramas y commits en GitHub; cierre | IE9, IE11 |
